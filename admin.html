Как пользоваться панелью
  1. Найдите квартиру по блоку, этажу и номеру. ID модели открывает точную квартиру.
  2. Откройте «Изменить», выберите статус и при необходимости укажите общую цену в TJS. «В черновик» сохраняет правку только в этом браузере.
  3. Подключите GitHub и нажмите «Проверить и опубликовать». После подтверждения дождитесь сообщения о появлении данных на сайте.
  4. CSV выгружает текущую отфильтрованную выборку, включая ваши черновые правки. GitHub хранит историю опубликованных изменений.

Для первого подключения: GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
