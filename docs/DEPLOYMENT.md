# Публикация сайта

Репозиторий содержит исходники и проверенную сборку в `dist/`. GitHub Actions публикует именно эту сборку через GitHub Pages при изменениях `dist/` в ветке `main`. Права публикации ограничены заданием развёртывания; версии официальных действий закреплены по SHA.

Публичный сайт: https://abubakrmmarufov-tech.github.io/3D-one-room/

16 октября 2026 года владелец разрешил сделать репозиторий публичным. GitHub Pages включён, HTTPS обязателен. Первое успешное развёртывание: [38851971123](https://github.com/abubakrmmarufov-tech/3D-one-room/actions/runs/38851971123), сборка приложения из коммита `1e84d2216e3e5c162538334682a42451eda857c2`.

Для обновления:

```sh
npm ci
npm run package:offline
npm run check:package
npm run check:motion
```

После проверки изменений сохраните исходники и `dist/` в Git и отправьте в `main`. Рабочий процесс также можно запустить вручную в разделе Actions. Публикация требует включённого GitHub Pages и подходящего тарифа для частного репозитория либо публичной видимости репозитория.

`DELIVERY_MANIFEST.json` перечисляет файлы поставки репозитория, включая конфигурацию хостинга и документацию; сам манифест исключён. Файлы приложения и `dist/` не изменены относительно локальной проверенной редакции.

## Проверка публичного адреса

17 файлов загружены без авторизации и совпали с проверенной сборкой по SHA-256. В новом контексте Chromium пройдены 14 проверок публичного сайта, включая все пять комнат, детали, план, возврат и мобильную компоновку. Ошибок выполнения и HTTP нет. Отчёты и снимки находятся в `qa/hosted/`. Это дополнительные проверки публикации; ограничения проверки физических устройств из `QA.md` сохраняются.
