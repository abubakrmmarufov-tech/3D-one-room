# Управление квартирами

Панель: [открыть управление](https://abubakrmmarufov-tech.github.io/3D-one-room/admin.html). Кнопка «Управление» также есть в 3D-просмотре.

Если после обновления виден старый интерфейс, закройте открытые вкладки этого сайта и откройте ссылку заново: офлайн-копия переключается на новую версию между сеансами.

## Первое подключение — владелец репозитория

1. Войдите в GitHub как **abubakrmmarufov-tech**. В панели нажмите **Подключить GitHub → Создать токен на GitHub**.
2. Выберите **Resource owner: abubakrmmarufov-tech → Only select repositories → 3D-one-room**.
3. В **Repository permissions → Contents** выберите **Read and write**, задайте срок действия и создайте fine-grained token. Другие дополнительные разрешения не нужны.
4. Скопируйте токен в поле панели и нажмите **Подключить**. Не отправляйте его в чат и не передавайте коллегам. Панель удаляет токен из памяти при выходе или перезагрузке вкладки; затем его нужно ввести снова. Сам токен GitHub остаётся действительным до истечения срока или отзыва в GitHub.

Токен даёт право менять содержимое выбранного репозитория, а не только статусы квартир. Храните его как пароль, выбирайте короткий срок и отзывайте через GitHub при необходимости. GitHub сам проверяет права записи. Инструкция по токенам: [официальная документация](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens).

## Каждый день

1. Найдите квартиру по блоку, этажу, комнатам, номеру или ID. **B** означает блок **Б**. Например, `B12-0` — квартира №57 в блоке Б на 12-м этаже. Ссылка **3D ↗** открывает именно её.
2. Нажмите **Изменить**, выберите **Свободна / Бронь / Продана / Статус не указан**, при необходимости укажите общую цену квартиры в **TJS**. Пустая цена скрывается в просмотре.
3. Нажмите **В черновик**. Можно изменить несколько квартир. Правки пока видны только в вашем браузере.
4. Нажмите **Проверить и опубликовать**, проверьте «Было / Будет», затем **Опубликовать**. Дождитесь сообщения **«Опубликовано»**. До него данные могут быть только сохранены в GitHub; публикация обычно занимает 1–3 минуты, иногда дольше.
5. После работы нажмите **Выйти**.

## Полезные функции

- Сводка показывает все 128 квартир. С активным черновиком она учитывает ваши правки; список можно отфильтровать отдельно.
- **Скачать CSV** выгружает текущую выборку. Если есть правки, в имени файла будет `draft`.
- Черновик восстанавливается после перезагрузки в том же браузере. **Скачать черновик** создаёт резервную JSON-копию; восстановление находится внизу в **Как пользоваться панелью**. Для другого черновика сначала скачайте или отмените текущий.
- **Обновить** проверяет данные. Если ту же квартиру изменил другой редактор, публикация остановится. Скачайте свой черновик, отмените правки, обновите данные и внесите нужное изменение заново.
- При плохой связи показана сохранённая копия с предупреждением. Для публикации нужен интернет. Если сохранение оборвалось, сначала обновите данные: GitHub мог уже принять запись.
- История изменений: [коммиты файла статусов](https://github.com/abubakrmmarufov-tech/3D-one-room/commits/main/public/inventory.json).

## Границы этой версии

Это панель владельца на существующем GitHub Pages. Смотреть реестр и готовить локальный черновик можно без подключения; публиковать может только пользователь с правами GitHub. Для отдельных логинов сотрудников и закрытой CRM нужна отдельная служба авторизации. Не передавайте свой токен сотрудникам.

Статусы и цены публичны, персональные данные покупателей здесь не хранятся. Панель не оформляет продажу и не гарантирует бронь в реальном времени. Все квартиры изначально имеют **«Статус не указан»**: подтверждённые сведения вводит владелец. В реестре только блок Б. Номера служат навигации в модели, площади требуют проверки по документации.
